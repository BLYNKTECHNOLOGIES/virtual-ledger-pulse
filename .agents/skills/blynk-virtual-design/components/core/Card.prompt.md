Every panel, tile and metric block in the system is a Card.

```jsx
<Card><h3>Fleet health</h3><p>412 of 418 devices reporting.</p></Card>
<Card tone="inverse" padding={32}>…</Card>
<Card interactive onClick={open}>…</Card>
```

Radius 14px, hairline border, `--shadow-sm`. No coloured left-border accents.
