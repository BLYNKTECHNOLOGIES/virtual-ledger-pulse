Wraps a Lucide glyph — the only icon set in the Blynk system. Use for every UI affordance; never emoji, never hand-drawn SVG.

```jsx
<Icon name="activity" />
<Icon name="chevron-right" size={16} />
<Icon name="shield-check" size={28} color="var(--cyan-500)" />
```

Loads the Lucide UMD build from CDN on first mount. Default 20px box, 1.75px stroke; drop to 1.5 above 32px.
