# Console UI kit — Blynk Virtual Technologies

**Status: extrapolated, not a recreation.** No application code, Figma file or screenshot was supplied
for this brand — only the three logo files in `uploads/`. These screens show the token system and
component library on a realistic operations console so designers have a working reference. They do
**not** replicate a real Blynk product view.

| File | Screen |
| --- | --- |
| `Shell.jsx` | App frame: ink rail + glass top bar |
| `OverviewScreen.jsx` | Fleet KPIs, alerts, activity |
| `DevicesScreen.jsx` | Filterable device table with a reboot dialog |
| `SettingsScreen.jsx` | Form-heavy settings with toggles |
| `index.html` | Interactive click-through of all three |
